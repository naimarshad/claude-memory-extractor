A `SessionEnd` hook (`~/.claude/hooks/memory_extractor.py`) distills every session's transcript into an Obsidian memory vault, organized into `Context/`, `Plans/`, `Decisions/`, `Mistakes/`, `DosDonts/`, `Incidents/`, and `Sessions/`, with a generated `Index.md`. This is a personal cross-session log, not a substitute for repo `CLAUDE.md` files.

Which vault a project feeds depends on the directory it runs in: routing lives in `~/.claude/memory-extractor.json`, and `python3 ~/.claude/hooks/memory_extractor.py --resolve-vault "$PWD"` prints the vault for the current one. Vaults are kept separate on purpose (for example personal versus work), so never read across from one into another.

Check that vault's `Index.md` at the start of substantive work in any project and filter to entries whose frontmatter `project:` matches the current repo, since it may hold decisions, mistakes, or open plans from earlier sessions that aren't written down anywhere else. If the vault or hook script is missing or looks broken, say so rather than silently skipping it.
